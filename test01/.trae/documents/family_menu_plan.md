# 家庭点菜与食材储备管理系统 - 实施计划

## 项目概述

- **项目名称**: 家庭点菜小助手
- **项目类型**: 微信小程序
- **核心功能**: 家庭成员点菜、食材库存管理、智能采购建议
- **目标用户**: 个位数家庭成员（小范围使用）
- **数据同步**: 所有用户实时共享数据

---

## 系统架构设计

### 技术选型
- **前端**: 微信小程序原生开发 (WXML, WXSS, JavaScript/TypeScript)
- **后端**: 微信云开发 (Cloud Functions + Cloud Database)
- **数据存储**: 云数据库 (JSON 文档型)

### 数据库设计
1. **菜品表 (recipes)**: 菜品信息、分类、图片、制作时间
2. **食材表 (ingredients)**: 食材基础信息、单位
3. **菜谱材料表 (recipe_ingredients)**: 每个菜品需要的食材及用量
4. **库存表 (inventory)**: 当前家庭食材储备
5. **点菜记录表 (orders)**: 用户点菜记录
6. **用户表 (users)**: 家庭成员信息

## 技术实现要点

### 微信云开发优势
1. 无需自建服务器，降低成本
2. 原生支持实时数据推送
3. 数据库自动同步，无需额外开发
4. 支持云函数处理复杂逻辑

### 核心计算逻辑
```
所需食材 = Σ(菜品所需食材 × 点菜数量)
库存缺口 = 所需食材 - 当前库存
采购清单 = max(0, 库存缺口)
```

### 单位统一处理
- 统一使用克(g)作为内部计量单位
- 界面展示时转换为kg/L等友好格式
- 支持单位换算：1kg = 1000g, 1L = 1000ml
